AI / An empirical notebook

Can we measure
AI know-how?

How much do model size and inference expenditure explain—and what remains uncertain about training resources and laboratory know-how?

Benchmark snapshot: 2026-10-06 · Intelligence Index v4.3.2 · 35 verified open-weight models
Le Chonk token supplement: 2026-10-08

Mistral Large 4, nicknamed Le Chonk, scores below leading proprietary models on the same benchmark index. Its technical documentation lists 1.05T stored parameters and 52.0B active per token; its launch announcement says 49.0B active. Those numbers describe architecture, but do not disclose the resources spent training it or answering benchmark questions. The performance gap could reflect any of those resources, different engineering choices, or both.

This analysis compares documented architectures, estimates how performance relates to observable resources, and examines the differences left unexplained. A difference from the fitted expectation is called a model efficiency residual. Section 03 defines the calculation.

The outcome is the Artificial Analysis Intelligence Index, a composite of ten evaluations rather than a complete measure of intelligence. Higher is better within the same index version. The main comparison uses 35 open-weight models with documented sizes and confirmed current-version benchmark measurements; Le Chonk is a separate, held-out example. Benchmark methodology · Le Chonk documentation.

Findings at a glance

  • Active size alone is a weak predictor: it explains 5.3% of score variation in this mixed sample. Adding generated output raises that to 64.7%; adding capacity and release date raises it to 81.8%.
  • Le Chonk exceeds the size-only expectation by +13.7 index points. Adding generated output reduces that residual to +2.9; the fuller adjustment gives +0.1, close to zero. Both adjusted intervals include zero.
  • The remaining differences cannot be assigned to know-how: training budgets, hidden inference work and measurement differences are not fully observed. The results describe associations, not equal-budget experiments.

Terminology used in the charts. KHI stands for Know-How Index, the working name for the model efficiency residual. The suffix identifies the adjustment: S = size, C = compute (an inference proxy), and F = fuller observable resources. Section 03 defines each calculation.

01 Active size: work per token, not the whole budget

A dense model uses almost all its backbone parameters for each token. A mixture-of-experts (MoE) model routes each token through a subset of its experts, together with shared layers. Its total stored parameters represent capacity; its active parameters are closer to one component of the work required to generate a token.

Le Chonk activates about 5.0% of its published backbone. The remaining weights still require memory and training, and can support specialization. A trillion stored parameters therefore does not imply a trillion parameters of computation per token. Attention, memory access and auxiliary modules also consume resources, so active size is an approximation.

The size-only regression predicts Intelligence Index from the logarithm of active size:

Predicted index = 12.93 + 6.85 log₁₀(active billions)

A tenfold increase in active size corresponds to 6.9 predicted index points. However, the 95% family-bootstrap interval for that coefficient is −2.2 to +15.4, which includes zero. This sample mixes architectures, generations and inference settings; it does not establish a stable cross-model scaling law.

That finding does not reject scaling within a controlled model family. It means active size alone does little to order these independently trained models. The next comparison adds the number of tokens generated, because work per token and work per answer are different quantities.

02 Inference expenditure: how much work goes into an answer?

Two equally sized models can use very different inference budgets. One returns a short answer; another generates a long reasoning trace before answering. A size-only comparison can make additional test-time spending look like greater efficiency.

Decoding compute proxy ∝ active parameters × generated tokens

The chart uses Artificial Analysis’s reported tokens per benchmark task. The reasoning view includes 29 models with positive reasoning counts. The all-output view includes answer tokens as well as reasoning, retaining non-reasoning models. Public comparison tables provide rounded counts; the authenticated API provides precise index scores. Le Chonk’s newly documented token counts add a held-out point to both views without changing either regression.

A regression on the product forces equal weights on log size and log token count. Fitting those two terms separately describes the same positive-reasoning sample better: R² is 0.625, compared with 0.507 for the product. R² is the share of score variation described by the fitted model; it is not a causal share attributable to compute.

The main compute-adjusted comparison uses separate terms for active size and all generated output. It retains the same 35 models as the size baseline. Prediction error when entire model families are held out falls from 13.5 to 8.8 index points. This is a useful predictive association, supported by the smaller reasoning-only comparison.

These proxies are not floating-point operations (FLOPs). They omit input processing, attention, hidden or parallel work and differences between tokenizers. Output length also depends on success, failure and verbosity. Conditioning on it may remove part of capability alongside expenditure. A causal test would vary the inference budget of the same model on the same tasks.

03 Defining the efficiency residual

The Know-How Index (KHI) is the observed Intelligence Index minus the score predicted from a specified set of resource measurements. Despite its name, it does not directly measure laboratory know-how; model efficiency residual is the more precise description.

KHI = observed index − predicted index

A residual of +5 means five index points above the fitted expectation; −5 means five below. Each version uses a different expectation:

Three adjustments, three different questions
Label and full namePrediction usesWhat remains unmeasured
KHI-S · Size-adjusted Know-How IndexLog active parametersInference duration, training resources and other differences
KHI-C · Compute-adjusted Know-How IndexLog active parameters + log generated output tokensExact inference FLOPs and training resources
KHI-F · Fuller-resource Know-How IndexLog active + log total parameters + log output tokens + release dateActual training compute and hidden inference work; exploratory

The additional date-adjusted view includes active size and release date alone. The raw residual in index points is the primary result. A standardized version divides it by the fitted residual standard deviation; the optional display score is 100 + 15 × that standardized value. A score of 115 therefore means one fitted residual standard deviation above expectation, not 15% more know-how.

Under the size baseline, MiMo-V2.6-Pro has the largest positive residual (+22.2 points) and Devstral 2 the largest negative one (−18.7). Under the fuller baseline, the extremes become DeepSeek V3 (Dec '24) (+9.9) and Nemotron 3 Super 120B A12B (Reasoning) (−15.7). The changing ranking shows why a residual must always name its baseline.

The bars quantify uncertainty in that baseline. They omit unavailable benchmark measurement error, and overlapping intervals do not establish a reliable ordering. Before applying these comparisons to Le Chonk, two additional observable differences need attention: stored capacity and model generation.

04 Capacity and model generation change the expectation

Adding total capacity to active size raises R² from 0.053 to 0.355. Among MoE models alone, it rises from 0.177 to 0.377 on 26 observations. Stored capacity adds predictive information, but active and total size are correlated design choices.

The joint models can produce negative active-size coefficients. That does not imply that activating fewer parameters causes better performance. Uneven coverage, correlated predictors and omitted training variables prevent that interpretation.

Adding release date to active size raises R² to 0.664. Newer models differ in training data, algorithms, distillation, post-training and inference behavior. Date summarizes those changes together; it is not a direct measure of technology or training budget.

The fuller model combines active size, total capacity, output tokens and date. Its adjusted R² is 0.794, but its family-held-out prediction error remains 7.1 points. The improvements are substantial, yet leave an important omission: resources spent creating the models.

05 Training resources change the comparison

Inference compute is spent producing answers; training compute is spent creating the model. A smaller model trained on more data, or with expensive reinforcement learning and teacher supervision, can outperform a larger model. Neither active size nor generated benchmark tokens establishes an equal training budget.

Le Chonk was trained from scratch on a much smaller reported cluster

Mistral reports training its own base model from scratch on 3,800 NVIDIA Grace Blackwell GPUs in its European datacenters. Euronews, which attended the press conference, reports two months; its rounded 4,000-GPU figure is replaced here by the official written count. For Astra, Greg Brockman describes a run on more than 100,000 GPUs. These are substantial disclosures, although they do not establish complete training budgets.

Graphics processing units (GPUs) and tensor processing units (TPUs) describe hardware. Their count measures cluster size, while GPU-hours combine count and duration; floating-point operations (FLOPs) measure arithmetic work. Using a 60-day approximation for Mistral’s two months, constant allocation of all 3,800 GPUs would give about 5.5 million scheduled GPU-hours. This is a scenario, not reported utilized GPU-hours. Allocation can vary, and reinforcement learning was still continuing at preview launch. Astra’s duration is unavailable in the cited interview, which also does not specify chip type. A common total-FLOP comparison remains unavailable.

Distillation can move training work outside the student’s budget

Distillation trains a student model to imitate a teacher’s answers or probability distributions. The student can inherit capabilities developed with a much larger resource budget. Gemma 3 uses distillation during pretraining; Nemotron 3 Ultra uses more than ten specialized teachers during post-training. Counting only student training omits the cost of producing teacher targets and, for complete resource accounting, an appropriate share of developing those teachers. Incremental student cost and the cost of creating the capabilities are different questions.

“Trained from scratch” describes the starting weights. It supports Mistral building its own base model rather than adapting an existing checkpoint. It does not by itself exclude synthetic data, teacher-generated examples or later distillation. The collected Mistral disclosures do not establish a complete teacher-cost breakdown. Distillation can improve deployment efficiency while shifting training work to the teacher.

06 Le Chonk: new token data change the reading

Technical documentation gives 1.05T total and 52.0B active parameters, plus a separate vision encoder; the launch announcement gives 49.0B active. The analysis prefers the technical card and retains the 49.0B–52.0B range. Le Chonk remains a held-out preview: its weights were unavailable at the benchmark snapshot, and it does not influence the open-weight fits.

The Artificial Analysis comparison table checked on October 8 now supplies approximately 69,000 output tokens per task, including 52,000 reasoning tokens, on Intelligence Index v4.3.2. The reasoning tokens are part of the output total, not an additional quantity. These weighted task averages provide the missing input for KHI-C and KHI-F.

An authenticated API check confirms the same model identity, release date and exact score of 38.4. The public table also displays all ten index evaluations without an estimated-score marker. The October 6 scores and regressions remain fixed; the October 8 token observation is explicitly recorded as a supplement. This supports the configuration match, although hidden changes to the ongoing preview cannot be independently excluded.

The large size-only residual largely disappears after accounting for additional observable resources. Le Chonk exceeds the size-only expectation by +13.7 points. Including its output budget reduces that to +2.9; adding capacity and release date gives +0.1. The fuller model predicts 38.3 against the observed 38.4. This change is the central lesson of the example: a size-only comparison can fold additional inference work and stored capacity into an apparent efficiency advantage. A near-zero KHI-F means Le Chonk sits close to this fitted expectation. It does not imply an absence of engineering skill, nor prove that any single resource caused its performance. Training resources, including the from-scratch run discussed in Section 05, remain outside the regression.

Token rounding, parameter uncertainty and the Scale Efficiency Multiplier

The published output count has thousand-token resolution. Treating its rounding bin as 68.5k–69.5k changes the point KHI-C to +3.0 to +2.8 and KHI-F to +0.2 to +0.1. This is small compared with baseline uncertainty.

SEM means Scale Efficiency Multiplier. It expresses a size-only residual as the ratio between a fitted equivalent active size and the observed active size:

SEM = 10KHI-S / size coefficient

Le Chonk’s size-only point calculation remains 100×, but its 95% uncertainty is unbounded because the size coefficient’s interval includes zero. The new token-adjusted results show why that size-only multiplier is unsuitable as a headline or a measure of saved compute.

The revised residuals explain its placement relative to the open-model baselines. The next comparison shows the remaining benchmark gap to proprietary leaders.

08 Reliability: related models, selected data and missing resources

The core contains 35 models across 19 families. Several sizes or releases from one family share training history and are not independent laboratory replications. Uncertainty calculations resample whole families, and prediction checks exclude whole families before refitting.

Keeping one preselected representative per family gives a size coefficient of -0.48 and R² of 0.000. Removing one entire family at a time produces coefficients from 4.80 to 9.64. These checks reinforce the instability of the size-only relationship.

Most laboratories contribute only one or two independent families; only 2 of 11 have the minimum three families for the displayed laboratory interval. This supports sensitivity checks, not a persistent ranking of lab skill. Proprietary frontier programs are not represented by their labs’ open-model entries.

Coefficients, equations and uncertainty calculations

Ordinary least squares fits transparent additive models using base-10 log parameters and task-token counts. Time is measured in years since 2026-01-01. The compute-adjusted equation is:

Predicted index = -109.30 + 9.16 log₁₀(active billions) + 26.68 log₁₀(output tokens/task)

The intervals use 2,000 deterministic family-block bootstrap draws. They hold reported benchmark scores fixed, because task-level score uncertainty is unavailable. HC3 is a standard-error correction for unequal residual variance; family and laboratory cluster standard errors allow approximate dependence within those groups. Few clusters and correlated predictors still limit precision.

Cluster standard errors use finite-sample corrections. The interval comes from resampling entire families, not from multiplying a standard error by 1.96. It is approximate with only 19 clusters. Design condition number: 63 (uncentered predictors).

Rounding sensitivity perturbs output counts within ±500 tokens. Parameter sensitivity uses cited alternative module counts and finite discrepancy ranges. These distributions are explicit assumptions, not calibrated measurements of every source of error. The downloadable methodology explains the calculations and inclusion rules.

09 Substantial residuals remain, but their causes stay open

Observable-resource differences explain considerably more than active size alone; meaningful unexplained differences remain. That result is compatible with differences in laboratory know-how, but also with unequal training budgets, hidden inference expenditure and measurement gaps.

An equal-budget comparison would need matched training resources and a controlled inference budget, beyond the inference proxy, with multiple independent models from each lab.

Le Chonk illustrates why the adjustment matters: +13.7 points above the size-only expectation, +2.9 after generated output, and +0.1 after the fuller resource adjustment. The C and F intervals cross zero; training-adjusted efficiency remains unavailable. Its gap to proprietary leaders is observable, and its reported training cluster is much smaller than Astra’s.
